This is a python 3d renderer I made from scratch for my school projects in year 9

Deps:
* numpy
* pygame

Features:
- import any OBJ file
- mouse control
- Hitboxes
- movement, sliding, crouching and clipping prevention when standing up in small spaces
- text based scene editor
  ```
  -b 0 0 0
  -o cube.obj 1 0 1
  -o sphere.obj 1 0 0
  -c 0 -3 0 100 2 100
  -c 0 0 0 2 2 2
  ```
